One dad joke, 86 characters, for make.fun's Dad Joke Showdown. A father tells his son at the dinner table that he finally brought home the bacon — and Mum wants to know why it is still oinking. It takes the old idiom literally, lands its pun on the first read, and puts the punchline at the very end, so it reads naturally when said out loud.

The entry is the joke itself: `main.ts` writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), after checking it is a single line of 1–200 characters and nothing but whitespace.

## Run it

```sh
node main.ts
```
